# Myanmar Community Manager Bot

🤖 Telegram Bot for community management with RPG game features.

## ✨ Features

- 📢 Announcement System with subscriber management
- 🎮 RPG Game (90-level story mode)
- 🏰 Dungeon Adventure Mode (infinite random dungeon)
- 📊 User statistics
- 📅 Scheduled messages
- 📡 Broadcast to users/groups
- 🚫 Blacklist management

## 🎮 Game Features

### Story Mode (`/game`)
- 90 levels with unique stories
- Choose your path (3 options per level)
- Level up with EXP system
- Equipment system (weapons, armor)
- Potion system
- Achievement system

### Dungeon Mode (`/dungeon`)
- Infinite random floors
- Random events: Combat, Treasure, Trap, Rest, Merchant
- Boss fights every 5 floors
- Shared character progression
